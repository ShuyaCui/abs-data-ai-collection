# 发行说明书预测回收字段切片设计

## 目标

从同一产品的《发行说明书》p102–104 生成四个产品级候选：初始资产池未偿本息费余额、`chinabond_predicted_recovery_rate`、`chinabond_predicted_recovery_amount` 和发行时预测现金流机构。

## 规则

1. 仅解析 p102–104 的原生文本，不调用模型或外部服务。
2. 必须同时出现：中债资信的预计回收总额、回收率，以及“采用中债资信预测的回收情况”的采用关系；缺任一项则不输出字段 36、37。
3. 中诚信国际的预测是独立预测来源，记录在字段 38 的机构数组中，但不得作为字段 36、37 的值。
4. 初始资产池余额仅接受 p104 “全部未偿贷款本息费总额”这一明确标签；单位从万元换算到元。
5. 发现重复、冲突或无法唯一绑定中债资信的金额/回收率时，返回空候选；不以相邻数值猜测。

## 样例预期

- 初始资产池余额：`3142587200` CNY（源文本显示 `314,258.72 万元`）。
- 中债预测回收率：`7.90` PERCENT。
- 中债预测回收金额：`2.482766` CNY_100M。
- 预测机构：中债资信（`adopted=true`）、中诚信国际（`adopted=false`）。

## 验证

- 单元测试覆盖成功、缺采用关系、重复金额/利率和中诚信不可覆盖中债四类情形。
- 真实样例走安全准入、证据工件持久化和 Excel 导出；工作簿无公式错误。
- 无已签字金标，因此本切片仅报告结构与证据验证，不报告业务准确率。
